# 개발 내역 추가 — ChromaDB + BGE-M3 (완료)

## 요약

로컬 임베디드 벡터 DB(`chromadb`)와 다국어·코드 친화 임베딩(`BAAI/bge-m3`)으로  
**샘플 few-shot · 헤더 심볼 · 프로젝트 소스 RAG**를 보강했다.  
임베딩은 CPU 전용으로 GTX 1080 Ti 11GB VRAM을 Qwen3 14B에 양보한다.

## 변경 파일

| 파일 | 변경 |
|------|------|
| `vector_store.py` | `bug_samples` / `header_symbols` / `source_chunks` 3컬렉션 |
| `samples_db.py` | 하이브리드 few-shot, ON/OFF 플래그 |
| `symbol_index.py` | 인덱싱 후 Chroma 동기, select_context chroma 보충 |
| `chunks.py` / `prompts.py` | 관련 소스 RAG 첨부 |
| `reviewer.py` | 검토 시 소스 인덱스 ensure |
| `app.py` | 샘플·헤더·소스 재구축 UI |
| `requirements.txt` | `chromadb`, `sentence-transformers` |
| `docs/04_...`, `docs/05_...` | 설계·완료 문서 |

## 사용 방법

```bat
pip install -r requirements.txt
START.bat
```

옵션 → **벡터 검색 사용** (기본 ON) → 샘플/헤더/소스 재구축.  
헤더 인덱싱 시 Chroma 헤더도 자동 동기화.  
프로젝트 루트를 두고 검토하면 소스 RAG가 자동 준비된다.

## 폴백

패키지 미설치·모델 로드 실패·질의 실패 시 키워드·exact·정규식으로 동작한다.
