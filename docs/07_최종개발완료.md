## 3. 실행·검증 한 줄 가이드

```bat
pip install -r requirements.txt
ollama pull qwen3:14b
START.bat
```

1. 옵션: 모델 `qwen3:14b`, 추론 **FAST**, 벡터 검색 ON  
2. 샘플/헤더/소스 인덱스 재구축 (필요 시)  
3. 헤더 루트 인덱싱 → 프로젝트 루트·소스 지정 → 검토  
4. 결과에서 few-shot 사유·헤더 `exact+vector`/`chroma`·관련 소스 RAG 확인
