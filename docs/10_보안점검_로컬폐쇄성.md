# 보안점검 — 로컬 LLM+RAG 폐쇄성 검증

| 항목 | 내용 |
|------|------|
| UI | 상단 **보안점검** 버튼 → 다이얼로그 |
| 목적 | Qwen/Llama + RAG 사용 시 데이터 외부 유출 여부 증빙 |
| 구현 | `security_audit.py` |

## 3단계

1. **네트워크 격리** — 오프라인에서 분석 성공 여부(수동 체크리스트)  
2. **아웃바운드 감시** — `netstat` ESTABLISHED / 방화벽 아웃바운드 차단  
3. **코드·텔레메트리** — 외부 URL 스캔, `HF_HUB_OFFLINE`, Chroma/Streamlit 통계 차단  

## 자동 적용

- `START.bat` / `app.py` 기동 시: `ANONYMIZED_TELEMETRY`, `HF_HUB_OFFLINE`, `TRANSFORMERS_OFFLINE`, `OLLAMA_HOST=127.0.0.1:11434`  
- `.streamlit/config.toml`: `gatherUsageStats = false`, `address = 127.0.0.1`  
- 증빙 리포트: `data/security/security_audit_*.md|json`
