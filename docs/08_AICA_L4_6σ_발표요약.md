## 언제 (When)

- 개발·검증: **2026.10 ~ 2026.11**
- 1차 완료: 2026.11.12 (Streamlit 검토 도구)
- 벡터·Qwen3 완료: 2026.11.16

## 왜 (Why)

- 레거시 C/C++ 소스는 **외부(클라우드)로 보낼 수 없음**
- 수동 검토만으로는 메모리·초기화 버그 누락·재현성이 약함
- LLM만 쓰면 줄번호·매크로·오탐 문제로 실무 적용이 어려움

## 어떻게 (How)

1. 정적 힌트(cppcheck / suspects)로 의심 구간 추출  
2. 함수 단위 청크 + `[L000n]` 줄번호 주입  
3. 로컬 Ollama(`qwen3:14b`) JSON 분석 → MD/CSV 리포트  
4. 헤더 SQLite + **Chroma/BGE-M3**(샘플·헤더·소스 RAG)  
5. 추론 모드 **FAST(기본) / AUTO / DEEP**

## 목적 (Purpose)

소스를 PC 밖으로 보내지 않고, **발견 → 근거 → 수정 제안**까지 재현 가능한 로컬 검증 체계를 만든다.

## 효과 (Effect)

| 효과 | 내용 |
|------|------|
| 보안 | 소스 외부 전송 0, 원본 파일 미수정 |
| 품질 | 헤더·벡터 RAG·few-shot으로 오탐·미탐 감소 기반 |
| 속도 | 함수 청크 + FAST 모드로 대량 창 고속 스캔 |
| 재현 | reports/ + docs/ + GitHub로 인수인계·재실행 |
