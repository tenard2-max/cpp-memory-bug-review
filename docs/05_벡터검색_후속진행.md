# 벡터 검색 후속 진행 (완료)

## 완료 항목

1. **샘플 선별 사유 기록**
   - `select_reason`: `vector` / `keyword` / `hybrid`
   - `select_score`, `vector_score`, `keyword_score`
   - 검토 UI 「모델에 넘긴 코드」에 `[hybrid:0.82]` 형태로 표시

2. **헤더 컨텍스트 exact + 벡터 순위 + Chroma 보충**
   - SQLite exact 후보 → BGE-M3 재순위 (`exact+vector`)
   - 예산이 남으면 `header_symbols` 컬렉션에서 유사 심볼 보충 (`chroma`)
   - 헤더 인덱싱(`build_index`) 직후 SQLite → Chroma 동기화

3. **프로젝트 소스 RAG**
   - 컬렉션 `source_chunks`: 함수 단위(최대 80줄) 청크
   - 검토 시작 시 `project_root` 기준 `ensure_source_chunk_index`
   - 분석 창마다 유사 함수 최대 2개를 프롬프트 `[관련 소스 RAG]`에 첨부
   - 옵션에서 샘플/헤더/소스 인덱스 개별 재구축

4. **샘플 Chroma 인덱스**
   - 옵션의 「샘플 재구축」또는 샘플 저장 시 `ensure_sample_index`
   - 영구 경로: `data/chroma/`

## Chroma 컬렉션

| 컬렉션 | 내용 |
|--------|------|
| `bug_samples` | few-shot 버그/오탐 샘플 |
| `header_symbols` | 헤더 심볼 정의 (SQLite와 동기) |
| `source_chunks` | 프로젝트 소스 함수 조각 |

임베딩: `BAAI/bge-m3` @ **CPU** (VRAM은 Qwen3 전용)

## 의도적 제외

| 항목 | 사유 |
|------|------|
| GPU 임베딩 | VRAM을 Qwen3에 양보 |
| FAISS / Docker Chroma | 로컬 임베디드만 유지 |

## 검증

```bat
pip install -r requirements.txt
```

1. 옵션 → 벡터 검색 ON → 샘플/헤더/소스 재구축  
2. 헤더 인덱싱 후 Chroma 헤더 건수 표시 확인  
3. 프로젝트 루트 지정 후 검토 → `소스 RAG N청크`, `관련 소스 RAG` 표시  
4. `context_included`에 `exact+vector` / `chroma` 확인
