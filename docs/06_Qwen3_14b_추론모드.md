# Qwen3:14b 추론 모드 (FAST / AUTO / DEEP) — 적용 문서

| 항목 | 내용 |
|------|------|
| 상태 | **완료** (Streamlit + Ollama, FastAPI/`project_status.ini` 미채택) |
| 기본 모델 | `qwen3:14b` (옵션에서 선택, 하위 호환으로 `qwen2.5-coder:7b` 유지) |
| 기본 추론 | **FAST** (`think:false` + `/no_think`) |
| 하드웨어 | GTX 1080 Ti 11GB — 임베딩은 CPU, VRAM은 LLM 전용 |

---

## 1. 원요건과의 차이

원본 기획(`DOC/qwen3_14b.md` → `docs/참고_DOC원본/qwen3_14b.md`)은 FastAPI·`project_status.ini`·별도 Modelfile(`qwen3-14b-fast`/`deep`)을 전제했다.  
본 프로젝트는 **기존 Streamlit 파이프라인**에 맞춰 아래만 채택했다.

| 원요건 | 적용 |
|--------|------|
| 단일 `qwen3:14b` + think 스위치 | ✅ `reviewer.qwen3_options` |
| FAST / AUTO / DEEP | ✅ 옵션 UI, 기본 FAST |
| `<think>` 분리·로그 | ✅ `logs/think/` |
| FastAPI 하이브리드 API | ❌ 미채택 |
| `project_status.ini` | ❌ 미채택 |
| 별도 Modelfile 두 개 | ❌ 파라미터로 대체 |

---

## 2. 모드 동작

| 모드 | 동작 |
|------|------|
| **FAST** | `think=false`, 프롬프트에 `/no_think`. 혼잣말 없이 JSON |
| **AUTO** | 1차 FAST → 의심/발견 시 같은 모델로 Thinking 재검토 |
| **DEEP** | 처음부터 Thinking 강제. think 본문은 `logs/think/` 저장 |

구현 위치: `reviewer.py` (`normalize_think_mode`, `qwen3_options`, `strip_think_blocks`, `review_paths`).

---

## 3. Ollama 권장 환경 (참고)

1080 Ti에서 100% GPU 적재를 목표로 할 때:

```bat
set OLLAMA_FLASH_ATTENTION=1
set OLLAMA_KV_CACHE_TYPE=q8_0
set OLLAMA_MAX_LOADED_MODELS=1
```

`num_ctx`는 옵션/하드웨어 프로필에 따르며, VRAM 여유에 맞게 조절한다.  
`ollama ps`에서 PROCESSOR가 GPU 위주인지 확인한다.
