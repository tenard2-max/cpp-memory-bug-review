# DB(헤더) 전처리 — 슬림 헤더 생성

| 항목 | 내용 |
|------|------|
| 목적 | 헤더 DB 크기 최소화 |
| UI | 헤더 인덱스 → **DB(헤더) 전처리** 다이얼로그 |
| 입력 | 전처리된 헤더·CPP 각 **최대 5개** |
| 추출 | **struct / typedef** 위주 (매크로·함수 선언 제외) |
| 출력 | `data/preprocessed/slim_*.h` |

## 동작

1. CPP에서 식별자·`타입 변수`·`변수.멤버`를 모은다.  
2. 선택 헤더에서 struct/typedef 블록을 파싱한다.  
3. 이름 매칭 + 의존 타입 최대 2단을 포함해 **구조 유지**한 새 `.h`를 저장한다.  

구현: `header_preprocess.py` · UI: `app.py` (`header_preprocess_dialog`)
