# 참고 — DOC 폴더 원본

프로젝트 루트 `DOC/`에 있던 **초기 기획·요건 원문**을 `docs` 아래로 복사해 둔 폴더다.  
구현 확정 내용은 상위 `docs/01`~`07`을 본다. 여기 파일은 의사결정 추적용이다.

| 파일 | 성격 |
|------|------|
| `1. 기능구현 그리고 검증및 고도화.txt` | 로컬 LLM+cppcheck 파이프라인 초안 |
| `2. 추가학습기능.txt` | few-shot·오탐 학습 |
| `3. 최종 점검.txt` | 점검 체크리스트 |
| `4. 대규모프로젝트.txt` | 대용량/배치 (후속 G-03) |
| `5.함수별 소거.txt` | 함수 단위 소거 |
| `6. DB방식과동적할당.txt` | 벡터 DB·임베딩 후보 검토 (Chroma+BGE-M3 채택 근거) |
| `qwen3_14b.md` | Qwen3 하이브리드 요건 (FastAPI 등은 미채택 → docs/06 참고) |

루트 `DOC/`와 내용이 같으면, 이후부터는 **`docs/`만** 갱신하면 된다.
